## 👨‍🏫 Overview
A bespoke, professional HTML5/CSS3/JavaScript slide presentation designed specifically for teaching HSC ICT Chapter 4. Reconstructed with high educational standards, pedagogical teacher notes, interactive live code examples, board CQ step-by-step reveals, and interactive MCQ quizzes—completely free of third-party branding or lecture scribbles.

---

## 🚀 How to Launch the Slide Deck

Simply open **[index.html](file:///run/media/sayedmaruf/Study/Ict%20coach/index.html)** in any web browser (Google Chrome, Microsoft Edge, Firefox, Brave, Safari):
- **Direct Launch:** Double-click `index.html`.
- **Optional Local Server:**
  ```bash
  python3 -m http.server 8000
  ```
  Then visit `http://localhost:8000/`.

## 📚 Curriculum & Slide Modules

1. **অধ্যায় পরিচিতি ও বোর্ড বিশ্লেষণ (Module 1):** Board mark distribution, question patterns (CQ & MCQ breakdown).
2. **ওয়েব ডিজাইনের মৌলিক ধারণা (Module 2):** Webpage vs Website, Browser vs Search Engine, IP Address (IPv4 vs IPv6), Domain Name, DNS, URL anatomy, Web Server & Hosting, Static vs Dynamic websites.
3. **ওয়েবসাইটের কাঠামো (Module 3):** Tree/Hierarchical, Linear/Sequential, Network/Web-linked, Hybrid/Combination structures with interactive SVG diagrams.
4. **HTML এর সূচনা ও মৌলিক গঠন (Module 4):** Tim Berners-Lee, HTML5, Basic skeleton, Container vs Empty tags, Tags & Attributes.
5. **টেক্সট ফরম্যাটিং ও হেডিং (Module 5):** Headings `<h1>` to `<h6>`, formatting tags `<b>`, `<i>`, `<u>`, `<s>`, `<mark>`, Subscript `<sub>` & Superscript `<sup>`.
6. **হাইপারলিংক ও ইমেজ (Module 6):** Anchor tag `<a>`, `href`, `target="_blank"`, Image tag `<img>`, Image as hyperlink.
7. **এইচটিএমএল লিস্ট (Module 7):** Ordered list `<ol>` (types, start), Unordered list `<ul>`, Nested lists.
8. **এইচটিএমএল টেবিল ও সেল মার্জিং (Module 8):** `<table>`, `<tr>`, `<th>`, `<td>`, `<caption>`, `border`, `colspan` (column merge), `rowspan` (row merge), Master complex table.
9. **বোর্ড সৃজনশীল প্রশ্ন সমাধান (Module 9):**
   - কুমিল্লা বোর্ড ২০২৩ CQ (Step-by-step reveal)
   - চট্টগ্রাম বোর্ড ২০১৯ CQ (Image, Hyperlink & Structure)
   - যশোর বোর্ড ২০১৭ CQ (List & Table formatting)
10. **জ্ঞানমূলক ও অনুধাবনমূলক প্রশ্নব্যাংক (Module 10):** Top 10 'ক' definitions & Top 5 'খ' comprehensive explanations.
11. **ইন্টারেক্টিভ বহুনির্বাচনী কুইজ (Module 11):** Interactive MCQ quiz with clickable options, green/red instant feedback, and detailed explanations.
12. **রিভিশন ও সমাপনী (Module 12):** 100% exam checklist & student guidance.

## 🎯 Teaching Features

- **👨‍🏫 Teacher Speaker Notes (`S`):** Built-in teaching drawer with pedagogy tips and common student mistakes for every slide.
- **🖊️ Digital Whiteboard / Annotation Pen (`P`):** Live drawing, highlighting, and writing directly on slides during class.
- **🔦 Presenter Laser Pointer (`L`):** Glowing red laser cursor for classroom focus.
- **📑 Slide Overview Grid (`O`):** Visual lightbox to jump to any slide in seconds.
- **💡 Step-by-Step CQ Reveal:** Click "উত্তর দেখুন" / "কোড দেখুন" to reveal answers interactively after asking students.
- **🧪 Interactive MCQ Quiz:** Click options to test students live with immediate feedback.
- **🖨️ Student Handout Ready (`Ctrl+P`):** Print-optimized layout to generate PDF study sheets.
